我的 GitHub 学习记录

我的第一次 GitHub Pages 实践

一、为什么开始学习 GitHub？

作为一名大学生，我希望能够学习更多编程和计算机相关知识。 GitHub 是程序员非常常用的平台，因此我开始学习 Git 和 GitHub。

二、Git 和 GitHub 的区别

Git 是一个版本控制工具，可以帮助我们记录代码的修改历史。 GitHub 则是一个基于 Git 的代码托管和协作平台。

三、我的第一次 GitHub Pages 实践

这次作业要求搭建一个基于 GitHub Pages 的个人博客。 我首先创建了自己的 GitHub 仓库，然后创建 index.html 文件。

随后，我通过 GitHub Pages 将网页部署到互联网上， 最终成功获得了自己的博客网址。

四、我学到了什么？

  • 了解了 GitHub 仓库的基本使用方法。
  • 了解了 HTML 网页的基本结构。
  • 了解了 GitHub Pages 的基本原理。
  • 完成了自己的第一个个人技术博客。

五、下一步计划

后续我计划继续学习 Python、Linux、ROS2 和人工智能，并把自己的学习过程记录下来。
