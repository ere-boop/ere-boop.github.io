Hexo 博客美化实战：从 Butterfly 主题到科技感设计

发表于2026-10-13|更新于2026-10-13|技术学习
|浏览量:

一、为什么要美化自己的博客？

在完成 Hexo 博客的基本搭建后，我开始思考一个问题：网站能够正常访问，只是第一步。如何让它具有更鲜明的视觉风格，让访问者更容易了解我的学习方向，才是下一步需要解决的问题。

我希望把博客改造成一个具有科技感的个人技术展示平台，主要记录自己在 ROS2、人工智能和编程方面的学习过程。

因此，这次改造的目标主要有三个：

  1. 统一视觉风格：采用深蓝色与紫色渐变，营造科技感。
  2. 优化页面组件：让文章卡片、侧边栏和导航栏更加精致。
  3. 增加交互效果：通过鼠标悬停动画、半透明背景等细节，让页面更有层次感。

本次改造基于已有的 Hexo 博客和 Butterfly 主题进行，没有重新搭建整个网站，而是通过自定义 CSS 调整页面样式。

二、认识 Hexo、Butterfly 和 CSS 的关系

在开始修改之前，我需要先理解网站中不同技术的作用。

  • Hexo：静态网站生成器。它可以把 Markdown 格式的文章、主题模板和配置文件转换成浏览器能够访问的网页。
  • Butterfly：Hexo 使用的博客主题，提供导航栏、文章列表、侧边栏等现成的页面结构。
  • CSS：控制网页的外观，例如背景颜色、字体、间距、圆角、阴影和动画。
  • 自定义 CSS：在不直接修改主题源文件的情况下，为网站增加自己的样式。

可以把这几者理解为：Hexo 负责生成网页，Butterfly 提供网页的基本结构和默认设计，而 CSS 负责调整这些元素的视觉表现。

五、本次改造的收获

这次博客美化让我对网页开发有了更具体的认识。

第一，我开始理解主题与自定义样式之间的关系。使用现成主题并不意味着只能接受它的默认设计，还可以通过独立的 CSS 文件逐步建立自己的视觉风格。

第二，我认识到 CSS 选择器的重要性。例如，#web_bg、#nav 和 #recent-posts > .recent-post-item 分别用于选中不同的页面元素。只有找到真正控制目标区域的元素，样式修改才能达到预期效果。

第三，我体验了一次比较完整的调试流程：检查网络请求、确认响应内容、读取计算样式、进行视觉测试，再修改正式代码并重新预览。

最后，我也意识到，视觉效果需要整体设计。背景、卡片、导航栏和动画如果各自为政，就很难形成统一的风格。因此，后续改造不能只追求单个元素的炫酷，还要考虑页面层次、阅读体验和整体一致性。

六、下一步计划

目前，我已经完成了博客基础视觉风格的第一轮调整。后续计划包括：

  1. 设计更有辨识度的首页视觉区域，突出个人技术方向。
  2. 为 ROS2、人工智能和编程学习记录增加更清晰的分类入口。
  3. 为项目展示区域设计具有统一风格的卡片和图标。
  4. 在保证阅读体验的前提下，加入适量的动画和动态背景。
  5. 继续学习 Git 和 Hexo 的工作流程，规范版本备份、本地预览和线上部署。

对我来说，这次改造不仅是让网站变得更好看，也是一次从使用现成工具到理解其工作原理的实践。

后续，我希望把这个博客逐渐发展为个人技术作品集，持续记录自己的学习过程、项目实践和阶段性总结。
